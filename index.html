📥 Descargas listas

Aquí quedarán los archivos que generes, con su botón de descarga. Ya no se descargan "a ciegas": cada archivo generado aparecerá en esta lista.

Si un archivo no se descarga al pulsar su botón dentro de esta vista previa, usa el botón ↗ Abrir de cada archivo para abrirlo en una pestaña nueva del navegador (fuera de la vista previa las descargas funcionan con normalidad).

Se fusionan en el orden del panel. Cambia el orden con las flechas ↑ ↓ de cada tarjeta o arrastrándola. El DOCX refundido incluye campo de Índice (en Word: clic derecho → Actualizar campos) y marcadores por cada documento; el PDF conserva los marcadores originales de cada PDF.

Qué conserva la conversión

Títulos y jerarquía, párrafos con negrita/cursiva, listas, tablas, imágenes, alineación, encabezados/pies detectados, tamaño y orientación de página y saltos de página.

⚠️ Honestidad técnica: ningún conversor reproduce el 100 % de todos los PDF. El PDF fija la posición visual y Word trabaja con texto fluido. Por eso tienes dos motores: Editable (recomendado para trabajar el texto) y Fidelidad visual (se parece más al original). Revisa siempre el informe de cada documento.

Llevarte la aplicación

⬇ Aplicación web (.zip) 🐧 Instalador Linux (.deb) 🪟 Instalador Windows (.msi)

El .zip contiene la app completa: descomprimir, pip install -r requirements.txt y ./run.sh. El .deb la instala en Linux con servicio. El .msi ya viene compilado e instala la app con accesos en el menú Inicio y el escritorio (requiere Python 3.11+ en el equipo). El proyecto WiX queda en la carpeta packaging/windows por si quieres recompilarlo.

🌐 Servicio externo de máxima fidelidad: no está configurado en esta instalación, así que ningún PDF sale de este servidor. El botón superior está deshabilitado a propósito: la app nunca enviará tus documentos a terceros sin tu autorización expresa y sin avisarte antes. Si en el futuro quieres conectar Adobe PDF Services u otro proveedor, dímelo y lo integro con aviso previo por documento.
